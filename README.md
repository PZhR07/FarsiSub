# FarsiSub

**ساخت زیرنویس فارسی از فیلم و صدای انگلیسی، با پردازش آفلاین و رابط فارسی.**

FarsiSub یک برنامهٔ Python برای ویندوز است که صدا را با FFmpeg استخراج می‌کند، گفتار انگلیسی را با Whisper به متن زمان‌بندی‌شده تبدیل می‌کند و با NLLB زیرنویس فارسی می‌سازد. پس از نصب و دانلود مدل‌ها، پردازش بدون اینترنت و بدون کلید API انجام می‌شود.

## امکانات

- دریافت مسیر فایل و انتخاب مسیر صوتی فیلم‌های چندزبانه
- خروجی زیرنویس فارسی SRT و VTT و زیرنویس انگلیسی SRT
- ویرایش متن، جست‌وجو، صفحه‌بندی و پیش‌نمایش در مرورگر
- ترجمهٔ ادامهٔ جمله‌ها با حفظ زمان‌های زیرنویس
- اجرای CPU و پشتیبانی اختیاری از GPU انویدیا
- توقف و ادامهٔ پردازش از مراحل ذخیره‌شده
- حفظ ویرایش‌ها هنگام ذخیره و مدیریت تعارض بین دو تب
- بررسی یکپارچگی مدل‌ها و نگهداری سه نسخهٔ اخیر خروجی

## نصب و اجرا

1. **Python 3.12 نسخهٔ ۶۴ بیتی** را همراه Python Launcher نصب کنید.
2. پروژه را دانلود و از حالت فشرده خارج کنید.
3. با اتصال اینترنت، `setup.bat` را اجرا کنید. این فایل محیط مجازی، وابستگی‌ها، FFmpeg و مدل‌ها را آماده می‌کند.
4. برای استفاده از GPU انویدیا، در صورت سازگاری سخت‌افزار و درایور، `enable_gpu.bat` را نیز اجرا کنید. استفاده از CPU به این مرحله نیاز ندارد.
5. `start.bat` را اجرا کنید. رابط در آدرس `http://127.0.0.1:8765` باز می‌شود.
6. مسیر کامل فیلم را وارد کنید، مسیر صوتی را انتخاب کنید و «ساخت زیرنویس» را بزنید.
7. پس از پایان، متن را بازبینی و خروجی را دانلود کنید.

پنجرهٔ اجرای برنامه را هنگام پردازش باز نگه دارید. دانلود مدل‌ها حدود ۱.۱ گیگابایت است؛ برای نصب پایه حداقل ۴ گیگابایت فضای خالی در نظر بگیرید. کتابخانه‌های اختیاری GPU فضای جداگانه نیاز دارند.

## حریم خصوصی و محدودیت‌ها

پردازش فایل‌ها و اجرای مدل‌ها محلی است. سرور روی `127.0.0.1` اجرا می‌شود و رابط برای استفاده روی همان رایانه طراحی شده است. نصب اولیه و دانلود مدل‌ها به اینترنت نیاز دارد.

ترجمه و تشخیص گفتار ممکن است در نام‌ها، اصطلاحات، موسیقی یا گفت‌وگوی هم‌زمان خطا داشته باشند؛ خروجی را پیش از انتشار بازبینی کنید. ترجمهٔ پیوسته، بخش‌های مجاور یک جمله را ترکیب می‌کند و حافظهٔ کل داستان ندارد. پخش برخی فرمت‌ها و انتخاب صدای پیش‌نمایش نیز به مرورگر بستگی دارد.

## ساختار پروژه

```text
FarsiSub/
├── app.py                 # سرور و API محلی
├── worker.py              # استخراج صدا، تشخیص گفتار و ترجمه
├── subtitles.py           # زمان‌بندی و قالب‌بندی زیرنویس
├── translation.py         # گروه‌بندی جمله‌ها برای ترجمه
├── outputs.py             # انتشار و نگهداری نسخه‌های خروجی
├── media.py               # بررسی مسیرهای صوتی
├── model_validation.py    # بررسی یکپارچگی مدل‌ها
├── download_models.py     # دانلود مدل‌ها
├── verify_models.py       # بررسی مدل‌های دانلودشده
├── static/                # JavaScript و CSS رابط
├── templates/             # قالب HTML
├── tests/                 # آزمون‌های Python و JavaScript
├── requirements.txt
├── setup.bat
├── start.bat
└── README_FA.md            # راهنمای کامل فارسی
```

پوشه‌های `.venv/`، `models/` و `data/` هنگام نصب و استفاده ساخته می‌شوند و در مخزن قرار نمی‌گیرند. فایل `.gitignore` این موارد را مستثنا می‌کند.

## آزمون‌ها

پس از نصب، از پوشهٔ پروژه اجرا کنید:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

برای آزمون‌های ویرایشگر، Node.js لازم است؛ اجرای خود برنامه به Node.js نیاز ندارد:

```powershell
node tests/test_editor.cjs
```

در آخرین بررسی، ۴۸ آزمون Python و ۱۱ آزمون JavaScript موفق شدند. مسیر کامل ساخت زیرنویس با مدل‌های واقعی روی CPU و یک فایل گفتار مصنوعی بررسی شده است؛ ارزیابی جامع کیفیت روی فیلم‌های متنوع و عملکرد GPU انجام نشده است.
